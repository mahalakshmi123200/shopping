# 🛒 Shopping Website

## 📖 Description
This is an online shopping website developed using PHP and MySQL.

## ✨ Features
- User Registration
- User Login
- Product Listing
- Shopping Cart
- Checkout
- Admin Dashboard

## 🛠 Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript

## 🚀 How to Run
1. Install XAMPP
2. Copy the project to `htdocs`
3. Import the database
4. Start Apache & MySQL
5. Open `http://localhost/shopping`
